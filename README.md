# Meeting You

Hinglish youth-romance visual novel set at Navrang Institute, Ahmedabad. A Rutvik Dangar game, v1.2.

- Season 1: 20 chapters (always ends happy, 4 endings)
- Season 2: 12 chapters, 2 saal baad, Mumbai
- Season 3: 5 chapters, final happy ending

Play: https://dkano350-a11y.github.io/meeting-you/

Sign in with Google; progress auto-saves to the cloud (Firebase) and resumes where you left off.
Files: index.html (engine + Ch1-2), chapters.js (Ch3-37), firebase-config.js, images.
